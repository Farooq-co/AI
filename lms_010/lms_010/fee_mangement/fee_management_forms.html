Fee management forms — tabbed interface covering all fee modules

Fee Management

Create and manage fee heads, invoices, payments, discounts, and student ledger records from a single dashboard.

Fee Head

Define fee categories such as tuition, transport, or lab fees.

POST fee_head/add_fee_head.php Table fee_heads

Fee Type

Set billing frequency — monthly, quarterly, annual, or one-time.

POST fee_type/add_fee_type.php Table fee_types

Fee Structure

Link fee heads and types to classes with defined amounts.

POST fee_structure/add_fee_structure.php Table fee_structures

Create Invoice

Generate a fee invoice for a student with optional adjustments.

POST fee_invoice/create_invoice.php Tables fee_invoices, invoice_items

Adjustments

Invoice number and line items are generated automatically from active fee structures for the selected class, plus the fee package amount when selected. Total = subtotal − discount − scholarship + fine.

Record Payment

Log fee payments with method, bank details, and verification status.

POST fee_payment/add_payment.php Table fee_payments

Bank / cheque details
Other

Receipt number is auto-generated (REC…) on save.

Fee Installment

Split an invoice into scheduled installment payments.

POST fee_installment/add_installment.php Table fee_installments

Student Discount

Apply percentage or fixed discounts for eligible students.

POST fee_discount/add_discount.php Table fee_discounts

Late Fine

Calculate and apply fines for overdue fee payments.

POST fee_fine/save_fine.php Table fee_fines

Fixed Fine = rate. Per Day Fine = rate × days overdue. Percentage Fine = rate% of invoice total (requires invoice ID).

Fee Waiver

Waive specific fee components for approved students.

POST fee_waiver/add_waiver.php Table fee_waivers

Payment Refund

Process refunds against verified fee payments.

POST fee_refund/add_refund.php Table fee_refunds

Student Ledger

View read-only balance summary for a selected student.

GET fee_ledger/view_ledger.php?id=… Table fee_ledgers

Balance summary

Ledger is a read-only student balance summary. Use fee_ledger/list_ledger.php to browse records, then view_ledger.php for details.
